# Executive Assistant

Matt's Claude Code executive assistant for Ethos delivery work: recaps, SDDs, SOWs, change orders, one-pagers, process flows, email drafts, and persistent per-client context.

## Start
1. Unzip, `cd executive-assistant`, run `claude`.
2. Paste the kickoff prompt from `KICKOFF.md`.

Daily use: `/recap`, `/email`, `/sdd`, `/onepager`, `/sow`, `/co`, `/flow`, `/review-design`, `/client-update`, `/new-client`. See `CLAUDE.md`.
