# Inbox Triage
Pull unread, filter noise, list Sender / Subject / Received / Needs. Ask which to draft and any direction (AskUserQuestion). Draft each via the email-draft skill and save as Outlook reply drafts. Every draft ends with the signature block from `standards/tools.md`. Never send. While reading, collect Matt's commitments and waiting-on items from the threads and propose Action Log rows (preview and confirm, Source = the email link).
